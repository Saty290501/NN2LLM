# Computational Graphs in Deep Learning

# Overview

Deep learning models are built from mathematical operations, but training
requires more than a final prediction. The model must retain how that
prediction was produced so it can assign responsibility for an error to each
parameter. A computational graph is that retained structure.

# Learning Objectives

After this chapter, you should be able to:

- Identify inputs, parameters, activations, and loss in a graph.
- Describe forward and backward passes.
- Explain why shared parameters receive accumulated gradients.
- Relate a small `Value` graph to a neural network computation.

# Theory

During the forward pass, a model transforms inputs into a prediction and then
computes a scalar loss. Each intermediate calculation becomes a graph node.
During the backward pass, derivatives flow from the loss toward the
parameters, following the same edges in the reverse direction.

# Intuition

The forward pass is like following a route from ingredients to a finished
meal. The backward pass asks how much each earlier decision affected the final
taste. The graph is the map needed to answer that question without guessing.

# Mathematics

A one-input neuron can be written as:

```text
z = x * w + b
prediction = activation(z)
loss = loss_function(prediction, target)
```

Here, `x` and `target` are data, while `w` and `b` are trainable parameters.
The loss is a scalar objective. Training needs derivatives such as
`d(loss)/d(w)` and `d(loss)/d(b)` so the parameters can be updated.

If a parameter affects the loss through multiple paths, its total derivative
is the sum of the derivative contributions from all paths. Gradient
accumulation is therefore a mathematical requirement, not an implementation
detail.

# Computer Science Perspective

The forward graph is a DAG whose nodes store values and local operation
context. A reverse traversal needs an order in which a node is processed only
after every downstream gradient contribution is available. A topological order
of the forward graph, reversed for the backward pass, provides that order.

# Deep Learning Perspective

For a full network, layers repeat this pattern:

```text
features -> linear layer -> activation -> linear layer -> loss
```

Parameters are leaves or early nodes in the graph, and the loss is the final
node. Backpropagation computes a gradient for every parameter that influenced
the loss. An optimizer then uses those gradients to reduce the loss over many
examples.

In inference mode, the model needs only the forward numerical values. In
training mode, it must also keep enough operation history for the backward
pass.

# Engineering Perspective

NN2LLM begins with scalar `Value` objects because the graph mechanics are
visible at this scale. The same concepts later apply to tensors: tensor nodes
represent batches or matrices, but their dependency and gradient rules remain
the same.

The graph must retain local information required by each operation. For
example, multiplication needs the other input value to compute its local
derivatives, while a power operation needs its exponent and base value.

# Connection to NN2LLM

The current `Value` class already records the forward-pass data, parents, and
operation label. Its `_backward` placeholder will later store a local-gradient
function. Graph traversal will determine the order in which those functions
run, beginning at a final output or loss value.

# Interview Questions

## Why is the loss usually a scalar?

A scalar gives training one objective to minimize and provides a natural seed
gradient of `d(loss)/d(loss) = 1`.

## Why do gradients flow backward?

The chain rule starts with the effect of the final loss and distributes that
effect through every operation that produced it.

## Why must gradients accumulate?

A variable may influence a result through multiple paths, and the chain rule
adds the contribution from each path.

# Common Misconceptions

- Backpropagation does not repeat the forward pass; it uses saved forward
  information.
- A graph is not only for visualization; it determines differentiation order.
- Parameters do not update themselves; an optimizer applies the update after
  gradients are computed.

# Key Takeaways

- Neural-network computation is naturally represented as a DAG.
- A forward pass produces values; a backward pass produces derivatives.
- The loss connects model error to every participating parameter.
- Reused values require gradient accumulation.
